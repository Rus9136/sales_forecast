# Handoff: Sales Forecast — Редизайн корпоративной панели аналитики

## Обзор

Полный редизайн внутреннего корпоративного сайта **Sales Forecast** (домен `aqniet.site`) — рабочий инструмент для:
- аналитики продаж по дням / часам / официантам;
- прогнозирования продаж по филиалам и сравнения факт vs прогноз;
- расчёта бонусов сотрудников и схем мотивации;
- управления справочниками сотрудников (1 639 записей) и подразделений.

Пользователи: бухгалтеры, финансисты, управляющие ресторанами. Холдинг Aqniet включает сети Madlen, Tary, Sandyq, Kainar (12 филиалов в 7 городах Казахстана).

## О файлах в этом пакете

Файлы в этой папке — **дизайн-референс**, прототипы на HTML/CSS/React (через Babel inline). Это не продакшн-код для копирования напрямую. Задача — **воспроизвести этот дизайн в существующем кодовом окружении сайта** (Vue/React/Angular/Next и т.п.) с использованием установленных в проекте паттернов и библиотек.

Все стили живут в `styles/*.css` через CSS-переменные (токены) — их можно перенести 1-в-1 в любой стек. Логика экранов в `src/screens/*.jsx` — описывает структуру разметки, иерархию данных и интерактив.

## Точность

**High-fidelity (hi-fi)** — финальные цвета, типографика, отступы, состояния, тени, анимации. Разработчик должен воспроизвести интерфейс пиксель-в-пиксель, используя компонентную библиотеку проекта.

### Цветовые токены (см. `styles/tokens.css`)
Используется OKLCH для предсказуемых тонов. Темы переключаются через `data-theme="light|dark"` на `<html>`.

**Акцентный цвет (изумрудный, по умолчанию):**
```

--accent-soft: oklch(0.95 0.04 162);   // light
--accent-soft: oklch(0.32 0.07 162);   // dark
```

Альтернативные акценты включаются через `data-accent="indigo|amber|slate"`.

**Светлая тема (основные):**

## Архитектура экранов

### 1. Shell (оболочка)
- **Sidebar (240px)**: бренд + 5 групп навигации (Аналитика / Продажи / Прогноз / Бонусы / Справочники) + футер с аватаром пользователя
- **Topbar (56px)**: бургер сворачивания, breadcrumbs, глобальный поиск с подсказкой ⌘K, колокол уведомлений, переключатель темы
- **Cmd+K (Ctrl+K)**: модальный палитровый поиск со списком всех разделов, навигация стрелками, Enter — переход

### 2. Дашборд
4 KPI-карточки (выручка, средний чек, чеки, бонусный фонд) с трендом vs предыдущий период и спарклайном; график «Факт vs Прогноз» (LineChart с заливкой и пунктирным прогнозом); heatmap 7×24 (день недели × час); топ филиалов и топ официантов с прогресс-барами.

### 3. Продажи по дням
Период (date-range) + филиал; bar chart по дням; таблица с sticky-шапкой, sticky-первой колонкой, чекбоксами bulk-действий, чипами активных фильтров, пагинацией.

### 4. Продажи по часам
4 KPI (всего, пиковый час, среднее, активных часов); bar chart 24 часа; таблица детализации.

### 5. Продажи по официантам
Карточки официантов в таблице (аватар + имя + рейтинг звёздами); сортировка по любой колонке; bulk-выбор.

### 6. Прогноз по филиалам
4 KPI; список филиалов с meter-баром выполнения плана и бейджем отклонения (pos/warn/neg); сегмент-фильтр «все / в зоне риска / перевыполнение».

### 7. Сравнение факт / прогноз
4 KPI (факт, прогноз, отклонение, точность MAPE); крупный line chart с двумя сериями; таблица точности по филиалам.

### 8. Бонусы (4 вкладки)
- **Расчёты**: bonus-summary, таблица с бейджами статусов (Согласован / На проверке / Черновик / Выплачен)
- **Схемы**: карточки схем (роли, база, ставка)
- **Ручной ввод KPI**: таблица с inline input
- **Помесячные планы**: матрица филиал × месяц, выделена текущая колонка

### 9. Сотрудники
Фильтры (должность, статус, поиск); 1 639 записей с пагинацией по 20; bulk-действия (назначить роль, перевести в филиал, деактивировать); чипы филиалов в ячейках; статус-бейдж с точкой.

### 10. Подразделения
4 KPI; карточки сетей (Madlen/Tary/Sandyq/Kainar) с филиалами; общая таблица.

## Состояние (state)

- `active`: текущий раздел навигации (`dashboard | sales-day | ...`)
- `theme`: `light | dark`
- `accent`: `emerald | indigo | amber | slate`

- `cmdkOpen`: boolean
- На каждом экране-таблице: `sort {k, d}`, `selected: Set`, `page`, фильтры

## Интеракции

- **Hover** на строке таблицы: `--row-hover`
- **Selected row**: фон `--accent-soft`, sticky-колонки наследуют тон
- **Bulk-toolbar**: при `selected.size > 0` шапка таблицы заменяется на ряд массовых действий
- **Sticky thead** + sticky первая колонка с `box-shadow: 1px 0 0 var(--border-faint)`
- **Cmd+K**: ловится глобально, фокус на input, навигация ↑↓, Enter — переход, Esc — закрыть
- **Tooltip графиков**: позиционируется относительно курсора, не вылезает за правый край

## Что важно при переносе в продакшн

1. **CSS-переменные → токены вашей дизайн-системы** (Tailwind config, MUI theme, Chakra theme и т.п.). Структура токенов в `tokens.css` совместима с любым подходом.
2. **Атрибуты `data-theme` / `data-accent` / `data-density` / `data-sidebar`** на `<html>` — простой способ управлять темой; можно заменить на классы или провайдер темы.
3. **Замените генератор `src/data.jsx`** на реальные API-вызовы. Структуры объектов (`BRANCHES`, `WAITERS`, `FORECAST`, `BONUS_CALCS`, `EMPLOYEES`) — это контракты, которые ожидают экраны.
4. **Графики** — рекомендуем заменить SVG на библиотеку, поддерживающую виртуализацию и большие наборы данных (Recharts / Apache ECharts).
5. **Таблицы** при больших объёмах (>500 строк) использовать виртуализацию (`react-virtual`, `tanstack-virtual`).
6. **Cmd+K** — можно использовать готовую `cmdk` библиотеку (от Vercel), сохранив наш визуальный стиль.
7. **Иконки** — можно заменить наш набор на Lucide / Phosphor / Tabler с теми же метриками (16×16, stroke 1.5).

## Браузерная поддержка

`oklch()`, `backdrop-filter`, `font-variant-numeric` — все современные браузеры (Chrome 111+, Safari 15.4+, Firefox 113+). Если нужна поддержка старее — использовать sRGB-фолбэки через PostCSS-плагин или сгенерировать hex-токены.
