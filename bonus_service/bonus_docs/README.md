# Bonus Service

Сервис для автоматизированного расчёта ежемесячных бонусов сотрудников ресторанной сети **Sandyq Group** (бренды Sandyq и Tary, 10+ локаций в Казахстане) на основе KPI и выручки из iiko.

## Что делает сервис

1. **Хранит** настраиваемые схемы расчёта бонусов (по локации × должности × периоду)
2. **Собирает** данные из источников: iiko (выручка), TCO (смены), CRM (отзывы), HR (укомплектованность), ручной ввод (аудит)
3. **Рассчитывает** бонусы по 5 моделям расчёта (см. `docs/02-calculation-models.md`)
4. **Возвращает** результат с полной расшифровкой (KPI, грейд, ставка, проработанные смены, удержания)
5. **Версионирует** схемы — расчёт за прошлый период использует старые ставки

## Главная идея архитектуры

Все ставки, проценты, грейды и распределения — **в БД и админке**, а не в коде. Когда HR меняет процент бариста с 1,3% на 1,5% — это `UPDATE` строки, а не правка кода.

Подразделения (KITCHEN, BAR_TEAM, и любые будущие) — это **универсальные команды (Team)** с настраиваемыми слотами и весами распределения. Добавление нового подразделения = `INSERT` в админке, без правки кода.

## Стек

- Python 3.12, FastAPI
- SQLAlchemy 2.0 (async), PostgreSQL 15+
- Alembic — миграции
- Pydantic v2 — схемы валидации
- pytest + pytest-asyncio — тесты
- Docker Compose — локальная разработка
- uv (или poetry) — менеджер зависимостей

## Глоссарий (важно!)

| Термин | Что это |
|---|---|
| **Локация** | Конкретный ресторан (Sandyq Astana, Tary Kainar, …) — 10 штук |
| **Должность** | Управляющий, Менеджер, Бариста, Официант и т.д. |
| **Команда (Team)** | Группа должностей с коллективным расчётом (KITCHEN — пример) |
| **Слот команды (TeamPosition)** | Конкретная позиция в команде («Су-шеф 1», «Су-шеф 2») со своим весом |
| **Схема (BonusScheme)** | Конфигурация расчёта = локация + должность/команда + модель + параметры |
| **Модель расчёта** | Алгоритм: `flat_by_kpi`, `revenue_percent_by_kpi`, `revenue_direct`, `combined_products`, `team_revenue_by_kpi` |
| **Грейд** | Диапазон % выполнения KPI → коэффициент (70-79% → 3%, 80-84% → 3,5%, …) |
| **ОВТ** | Общая выручка точки — из iiko, по «Сумме со скидкой» или «без скидки» |
| **iiko** | POS-система, источник выручки и продаж |
| **TCO** | Time Control Office — внутренняя система учёта смен (своя разработка) |
