## Должности

**Индивидуальные** (расчёт на одного сотрудника):
- Управляющий
- Менеджер (администратор / администратор-кассир)
- Кассир (есть не везде)
- Старший бариста
- Бариста (в Астане ещё подразделяется на middle и senior)
- Официант

**Коллективные** (расчёт на команду с распределением):
- KITCHEN — есть в Sandyq Astana, Sandyq Almaty, Tary Auysai

В будущем могут появиться:
- BAR_TEAM (бар-команда)
- DELIVERY (доставка)
- HOUSEKEEPING (уборщики)

**Важно:** архитектура должна позволять добавлять новые подразделения без правки кода.

## Период расчёта

Месяц. Расчёт делается в начале следующего месяца за предыдущий (например, 1-5 мая считаем апрель).

## Источники данных

| Источник | Что даёт | Текущий статус |
|---|---|---|
| **iiko** | выручка точки, продажи по ФИО, структура продукции (готовая/приготовленная) | API частично есть |
| **TCO** | смены сотрудников (своя система Rus'а) | внутренняя система |
| **CRM** | негативные отзывы, рейтинг ресторана | API уточняется |
| **HR** | укомплектованность штата, испытательный срок | вручную / 1С |
| **Аудит кухни / стандартов** | результат внутренней проверки | вручную |
| **План продаж / рентабельности** | план по месяцам | заводится один раз в начале года |

## Текущий процесс (без сервиса)

1. Управляющий ресторана **вручную считает** показатели по каждому сотруднику
2. Заполняет служебную записку с расчётами
3. Согласовывает с бухгалтером, финдиректором, гендиректором
4. Бухгалтерия начисляет

## Целевой процесс (с сервисом)

1. **Авторасчёт**: 1-го числа сервис тянет данные из iiko/TCO/CRM, считает черновик
2. **Ручной ввод**: HR/управляющий заполняет недостающие KPI (аудит, укомплектованность)
3. **Проверка**: управляющий просматривает и одобряет
4. **Утверждение**: финдиректор → гендиректор (электронная подпись/статусы)
5. **Выгрузка**: в 1С:ЗУП на начисление

## Удержания и штрафы (важно!)

Из положения:
- За нарушение трудовой дисциплины — до 100% удержания от бонуса
- За махинации с данными (скрытие позиций в стоп-листе) — до 100% + расторжение
- Сотрудники на испытательном сроке могут не получать бонус (по решению директора)
- Бариста: бонусы начисляются только после 3 дней стажировки

Сервис должен поддерживать:
- Указание процента удержания (0-100%) с обоснованием
- Флаг «испытательный срок» на сотруднике
- Учёт стажировки (бариста — 3 дня)

## Что критично для бизнеса

1. **Прозрачность**: сотрудник должен понимать, как насчитан его бонус (показать KPI, грейд, формулу)
2. **Аудируемость**: через 6 месяцев финдиректор должен открыть расчёт и увидеть все исходные данные
3. **Гибкость**: ставки и проценты меняются 1-2 раза в год — должно быть легко
4. **Корректность**: ошибка в копейку при выплате 100+ сотрудникам = скандал
